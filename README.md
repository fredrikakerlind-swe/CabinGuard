# CabinGuard by Haysquare

Produktkoncept från Haydays 2026: en smart enhet som lyssnar efter vatten, frost, intrång och larm i fritidshus. Ljudet analyseras lokalt och sparas aldrig.

Sidan är en statisk `index.html` som publiceras via GitHub Pages. Live demon använder ljudmodellen AST (Xenova/ast-finetuned-audioset-10-10-0.4593) via transformers.js och körs helt i webbläsaren.
