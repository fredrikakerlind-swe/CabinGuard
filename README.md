# CabinGuard by Haysquare

Produktkoncept från Haydays 2026: en smart enhet som lyssnar efter vatten, frost, intrång och larm i fritidshus. Ljudet analyseras lokalt och sparas aldrig.

Sidan är en statisk `index.html` som publiceras via GitHub Pages. Live demon använder YAMNet via MediaPipe och körs helt i webbläsaren.

## Presentation

`deck/index.html` is the CabinGuard presentation as a scrolling web page with a section menu, including two live parts: YAMNet listening to the room, and a cold room example that learns the normal state and flags deviations. `deck/slides.html` is the same content in presentation mode (arrow keys, F for full screen).
